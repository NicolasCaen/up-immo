# up-immo

## Description
Le plugin **up-immo** est conçu pour gérer les biens immobiliers dans WordPress. Il permet l'importation de données, la gestion des métadonnées des biens, et l'intégration avec l'éditeur Gutenberg pour afficher les informations des biens de manière personnalisée.

## Fonctionnalités
- Importation de données via des fichiers CSV.
- Gestion des métadonnées des biens immobiliers.
- Intégration avec Gutenberg pour créer des blocs personnalisés.
- Système de filtres pour nettoyer et formater les données importées.
- Gestion des tâches planifiées pour automatiser les importations.

## Installation
1. Téléchargez le plugin et extrayez-le dans le répertoire `wp-content/plugins/`.
2. Activez le plugin via le menu 'Plugins' dans WordPress.
3. Configurez les paramètres d'importation dans le menu 'Paramètres' sous 'Biens'.

## Utilisation
- Accédez à la page d'importation pour importer des données de biens immobiliers.
- Utilisez les blocs Gutenberg fournis pour afficher les informations des biens sur vos pages et articles.
- Configurez les tâches planifiées pour automatiser les importations régulières.
